# Intégration de `intuis`

Formulaire et design d’origine conservés. FormId demandé : `ADW-intuis` ; le CRM et Sheets utilisent les mêmes URL que les LP déjà adaptées. Le GTM reste inchangé. La case d'origine est conservée et sa valeur transmise comme consentement : elle reste obligatoire. Le simulateur local a été retiré.

L’envoi nécessite le SMS et le succès une confirmation CRM **ou** Sheets, non nécessairement les deux. Vérifier le routage du formId, la feuille, les CORS et les services réels avant déploiement. Les tests sont simulés.
